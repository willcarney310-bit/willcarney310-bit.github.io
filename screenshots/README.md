exact same filenames. They render across the landing page automatically.

| -------------------- | ---------------------------------------------- |

Tips:
- Use full-resolution portrait iPhone captures (e.g. 1206×2622). The layout

- Keep them as `.png` for crispness. No other changes needed — just drop and go.
